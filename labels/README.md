# Етикетка 100×35 мм — рекомендоване заповнення

## Короткий вердикт

У наданому тексті змішані **два різні SKU** (Dead Horse 200 г / лише Берлі та Unity 250 г / Virginia & Burley). На одну етикетку їх зводити не можна. Для 100×35 мм базовою рекомендацією взято **Dead Horse · 200 г · legal-first**, плюс окремий варіант «забивка».

## Що потрібно від вас (критично)

Відповіді на ці пункти дозволять зафіксувати фінальний друк без юридичних ризиків:

1. **SKU:** Dead Horse 200 г чи Unity 250 г? (окремі макети, якщо обидва)
2. **Фактичний склад:** лише Берлі чи бленд Вірджинія + Берлі? Гліцерин є/немає?
3. **Призначення 100×35:** зворот банки (legal), бічна смужка, чи стікер «як забивати»?
4. **Виробник:** повна назва ТОВ/ФОП, адреса, країна походження, контакт
5. **Партія / дата:** де друкується (етикетка / дно банки / лазер)?
6. **Бренд-активи:** логотип, фірмові шрифти, палітра (якщо є)
7. **Маркетинг на міні-етикетці:** залишати «любов», «420», HAND-CRAFTED? (рекомендація: ні на legal)
8. **Мова:** лише UA / UA+EN мікрорядки
9. **Друк:** цифровий / флексо / офсет; матова/глянець; білий підклад під темний фон?
